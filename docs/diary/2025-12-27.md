## 技術的な学び

### Admin UIとテキストファイル方式の違い

| 項目 | Admin UI (`/admin/vt`) | テキストファイル (`add_new_vt.txt`) |
|------|------------------------|-------------------------------------|
| 追加先 | 直接`vt_config.json` | 経由して`vt_config.json` |
| 初期値 | `page_en: null` | `page_en: null` |
| 翻訳後コマンド | `make vt-admin` | `make vt-quick` |
| 特徴 | 画像付き視覚選択 | テキストベース |
| 関連ページ発見 | Scrapbox API使用 | 手動 |

### Git Rebaseの重要性

- 複数環境（GitHub Actions、ローカル）で並行作業する場合、rebaseは必須
- `git pull --rebase && git push`パターンでコンフリクトを自動回避
- Makefileに組み込むことでヒューマンエラーを防止

### Schema.org実装のポイント

- `<meta name="description">`はOGPカードに表示されない（SEO/AI用のみ）
- `og:description`を追加するとOGPカードにテキストが表示される
- JSON-LDは`<script type="application/ld+json">`でHTMLソースに埋め込み
- VisualArtworkタイプが図解コンテンツに適切
