# 2025-11-28 - Visual Thinking Gallery: VT Related Links Deduplication

## 概要

Visual Thinking Galleryの「関連リンク」セクションに同じVTが重複して表示される問題（Problem 3）を解決しました。

## 実施した作業

### 1. 問題の特定

ユーザーから4つの独立した問題が報告されました：
1. ピックアップのビューがダサい（デザイン問題）
2. 消したはずのトートバッグなどが復帰している（データ整合性問題）
3. **関連リンクに同じものが何度も出てきている**（今回解決）
4. リンクの多いものを探す際に同じものの出現を重複カウントしている（アルゴリズム問題）

今回は**Problem 3**を解決しました。

### 2. 根本原因の分析

問題を詳しく調査した結果、以下の3つのレベルで重複が発生していることが判明：

#### 2.1 vt_config.jsonの重複エントリ
- **症状**: 同じ`page_ja`を持つエントリが複数存在
- **例**: VT 156とVT 209が同じページ「知識のネットワーク記法」を指していた
- **影響**: 11組の重複エントリが存在（総数250→239に削減）

#### 2.2 共有参照グループ間の重複（inter-group duplicates）
- **症状**: 異なる経由ページから同じVTセットにリンクしている場合、同じグループが複数回表示される
- **例**: 「知識のネットワーク記法」経由と「知識のピラミッド記法」経由で同じVT [76, 190]が表示される

#### 2.3 グループ内の重複（intra-group duplicates）
- **症状**: 1つのグループ内に同じIDが複数回含まれる
- **例**: `[x, x]`のように同一IDが重複

#### 2.4 直接リンクとの重複
- **症状**: 「このページから直接リンクされているページ」に表示されているIDが、「共通リンクを持つページ」にも表示される
- **例**: ページ192で、IDs 46, 193, 196が両方のセクションに表示されていた

### 3. 実装した解決策

#### 3.1 vt_config.jsonの重複削除

**スクリプト作成**: `scripts/remove_duplicate_vt.js`

```javascript
// page_jaでグループ化し、IDが最小のものを残す
duplicates.forEach(({ pageName, items }) => {
  items.sort((a, b) => a.id - b.id);
  items.slice(1).forEach(item => {
    idsToRemove.push(item.id);
  });
});
```

**削除されたID**: 197, 208, 100, 190, 205, 121, 217, 199, 215, 209, 235

#### 3.2 グループ間重複の削除

**ファイル**: `utils/vt_graph.ts:191-203`

```typescript
// vtIdsのセットが同一のグループを除外
const seen = new Set<string>();
const deduplicated: SharedRefGroup[] = [];

for (const group of sharedGroups) {
  const key = group.vtIds.join(',');
  if (!seen.has(key)) {
    seen.add(key);
    deduplicated.push(group);
  }
}
```

#### 3.3 グループ内重複の削除（防御的）

**ファイル**: `utils/vt_graph.ts:169-171`

```typescript
// Setでラップして重複を除外
const otherVtIds = Array.from(new Set(
  Array.from(vtIdsLinkingToTarget).filter((id) => id !== currentId)

```

#### 3.4 直接リンクとの重複除外

**ファイル**: `pages/[lang]/vt/[page].tsx:92-110`

```typescript
// 直接リンクのIDセットを作成
const directLinkIds = new Set(directLinks.map(link => link.id));

// 共有参照グループから直接リンクIDをフィルター
const sharedRefGroups = sharedGroups
  .map((group) => {
    const filteredVtIds = group.vtIds.filter(vtId => !directLinkIds.has(vtId));

    if (filteredVtIds.length === 0) {
      return null; // 全てフィルターされたグループをスキップ
    }

    return { via: group.via, vtLinks: /* ... */ };
  })
  .filter((group): group is NonNullable<typeof group> => group !== null);
```

## 技術的な学び

### Setによる効率的な重複除外

JavaScriptのSetを複数レベルで活用：
1. **値の重複**: `new Set(array)` で単純な重複除外
2. **グループの重複**: `Set<string>` でシリアライズしたキーを保存
3. **フィルター条件**: `Set.has()` でO(1)の高速検索

### フィルターチェーンの設計

```typescript
groups
  .map(transform)      // 変換
  .filter(exclude)     // 除外
```

各段階で`null`を返すことで、後段の`.filter()`で除外する設計パターン。

### TypeScriptの型ガード

```typescript
.filter((group): group is NonNullable<typeof group> => group !== null)
```

`is`キーワードで型を絞り込み、以降のコードで安全に使用可能。
